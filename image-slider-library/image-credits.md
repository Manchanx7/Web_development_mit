# Demo image sources

The sample demo uses landscape photographs served by the Unsplash image CDN. Each URL is included here so the image source remains visible and easy to replace.

1. Alpine lake reflection: [Unsplash image](https://images.unsplash.com/photo-1470770841072-f978cf4d019e)
2. Mountain lake: [Unsplash image](https://images.unsplash.com/photo-1501785888041-af3ef285b470)
3. Ocean shoreline: [Unsplash image](https://images.unsplash.com/photo-1518837695005-2083093ee35b)
4. Forest path: [Unsplash image](https://images.unsplash.com/photo-1441974231531-c6227db76b6e)
5. Mountain valley: [Unsplash image](https://images.unsplash.com/photo-1500530855697-b586d89ba3ee)

Image URLs use Unsplash's auto=format, fit=crop, and width parameters to request display-sized versions. The demo does not bundle the photos, so an internet connection is required to display them.
